# Pictura peinture

Site de Pictura peinture, artisan peintre dans l'Ain (01480) : présentation des services et estimation de devis en ligne.

- `index.html` : la page complète (logo inclus).
- Les tarifs se modifient en haut du script, dans `TARIFS`.
- Les demandes sont envoyées par e-mail via FormSubmit à l'adresse indiquée dans `ENTREPRISE.email`.
